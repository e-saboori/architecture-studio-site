# Architecture Studio Site

Static multi-page architecture portfolio website.

## Pages

- `index.html` - Home page with hero, intro, centered rotating photos, and CTA.
- `about.html` - Professional profile and selected experience summary.
- `photos.html` - Replaceable photo gallery.
- `contact.html` - Centered contact details.

## Preview Locally

Open `index.html` in a browser, or serve this folder with any static file server.

The site has no build step and no package dependencies.

## Publish With GitHub Pages

1. Create a new GitHub repository for this folder.
2. Push these files to the repository.
3. In GitHub, open **Settings** > **Pages**.
4. Choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Save and wait for GitHub Pages to publish.

See [GITHUB_PAGES.md](GITHUB_PAGES.md) for editing and deployment notes.
